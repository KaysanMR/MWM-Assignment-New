Golden Catch Canned Fish Storefront

Golden Catch is an ASP.NET Web Forms e-commerce application for browsing and purchasing canned fish products. It uses .NET Framework 4.8, SQL Server LocalDB, Forms Authentication, Bootstrap, and a database stored under App_Data.

Test Accounts

Use these accounts when testing the submitted application after the database seed data has been applied.

Role Username Password Purpose
Admin admin Admin@123 Access dashboard, manage users, products, categories, orders, and feedback.
Member member Member@123 Browse products, manage profile, wishlist items, checkout, and view order history.

Setup Requirements

  • Windows PC with Visual Studio 2019 or newer.
  • .NET Framework 4.8 targeting pack.
  • IIS Express.
  • SQL Server Express LocalDB.

How To Run

  1. Open MWM-Assignment-New.sln in Visual Studio.
  2. Restore NuGet packages if Visual Studio prompts for them.
  3. Confirm App_Data/myData.mdf exists in the project folder.
  4. Run the website using IIS Express from Visual Studio.
  5. Open Products.aspx to browse the storefront.

From PowerShell, the project can also be built with: .\tools\Invoke-WebsiteChecks.ps1

Application Walkthrough

  1. Visit the home page and open the shop/catalog page.
  2. Register a new account or sign in with the member test account.
  3. Browse canned fish products, view product details, and add items to the cart.
  4. Proceed to checkout to create a pending order.
  5. Use the customer order history pages to view previous purchases and order details.
  6. Sign in as admin to manage products, categories, users, orders, and feedback.

Project Notes

  • The main catalog page is Products.aspx.
  • Admin pages are stored under Admin/.
  • Customer-only pages are stored under Customer/.
  • The database connection string is named KeyboardShopDB for legacy reasons.
  • The business domain is a canned fish vendor storefront.
