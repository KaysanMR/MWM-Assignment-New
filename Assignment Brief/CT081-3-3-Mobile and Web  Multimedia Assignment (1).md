# CT081-3-3 Mobile and Web Multimedia Assignment Brief

Source PDF: `CT081-3-3-Mobile and Web  Multimedia Assignment (1).pdf`

## Project Context Summary

- Build an individual .NET e-commerce web application optimized for mobile devices.
- The application should be interactive, dynamic, well designed, and backed by SQL Server in `App_Data` using an `AttachDBFilename` connection string in `Web.config`.
- Required customer features include registration, login, profile management, product catalog/listings, shopping cart, purchase history, payment/notification support, delivery status, and feedback/ratings.
- Required admin features include managing users, products, categories, and orders with pending/cancel/delivery/delivered states.
- The site should have 10-20 interlinked pages, use ASP.NET Forms Authentication/authorization, Web Forms user controls, advanced Web Forms controls, data binding, validation, and mobile-friendly navigation/layout.
- Submission needs a report, user manual, zipped project files, and a static `ReadMe.html` with grader credentials and setup instructions.
